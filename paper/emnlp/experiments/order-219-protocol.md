# Clean fit on Universal Dependencies 2.19

Freeze the same 172 ISO codes, SHA-256-verified external source tables and engine 1.0.0 as in the 2.18 comparison. Use the 402 treebanks in the official UD 2.19 archive (SHA-256 6bbe2f0234dcc2d2367cc912848259c94c278ea69932d228d744f265a19a4a31). Start with an empty run directory. No prior learned order, corpus lookup table, rule table or model may enter a fit. Starting from the normalized source tables in their declared order, resolve individual lexical sources, build fresh corpus lookups and suffix rules from the current training fold, fit the exact full permutation and run the matched full cascade. Apply the original order protocol and the pre-existing two-fold supplement to this release without changing the thresholds. The two arms share their source membership, corpus and rule tables, feature settings, sentence positions and test words. The estimand is the effect of source order under a same-treebank fit. Treat language and token weighting separately. The archive overlaps earlier releases, so evaluation across the version boundary cannot establish independent corpus transfer.
