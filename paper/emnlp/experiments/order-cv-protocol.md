# Supplement for languages without a usable official pair

After inspecting split availability and before inspecting effect estimates, define a secondary two-fold evaluation for every multi-source language left outside the official-split estimate. Pool all scorable, unique sentences in its anchor treebank. Group by explicit document when possible, by sentence for ungrouped material, and by sentence within the one document when that is the only way to split. Assign whole groups deterministically to two folds by descending token count, using SHA-256 of the identifier to break ties and putting the next group in the smaller fold. Each fold's train set is the other fold. Do not use a development gate here. Every scored word receives out-of-fold predictions from both frozen arms. Report these languages separately, label the unit, and report a combined descriptive mean as a supplement. Bootstrap intervals for the official-split estimate remain primary; shared cross-validation training data limits an interval that fixes the fits.
