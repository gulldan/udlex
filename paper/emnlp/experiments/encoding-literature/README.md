# Lossless compression of form-to-lemma dictionaries

Research note for the encoding question (Q5), 19 November 2026. A dictionary must return the exact lemma bytes for a member and signal a miss for a nonmember. A stored identity mapping also counts as a hit. This contract lets us change the representation while holding lexical coverage, normalization and cascade order fixed. [Q5 protocol](../anatomy-protocol.md)

The follow-up OpenAlex search covers 19 November 2023 through 19 November 2026. It adds OnPair+, compressed offsets and static functions, together with a measured language profile and five testable hypotheses. [Обзор и гипотезы на русском](OPENALEX.ru.md) · [Search receipt](openalex-search.json)

## Where the bytes are

I audited all 172 dictionary wheels in the paper's UD 2.19 catalog, version `1.0.0.post1`, format 5. Their manifests list **578,374,683 bytes** of runtime data. The `exact.hybrid` tables account for **90.05%** of that total. Their long-slot records alone account for **74.09%**, compared with **3.50%** for `strings.txt` throughout the catalog. A long slot stores both the entire UTF-8 form and the entire lemma. Its original key is available to reject hash collisions on misses. Short keys of at most eight bytes follow a double-array trie. These proportions describe this particular catalog. Only Spanish Sign Language (`ssp`) has a nonempty `external` table here, with 547 entries. The multisource dictionaries used elsewhere in the study warrant a separate comparison. [Frozen catalog](../../../../dictionaries/ud-2.19/README.md) · [Hybrid format](../../../../rust/src/lexicon/table/hybrid.rs) · [Per-language counts](pilot.json)

## Size pilot

For each of the 171 packages with an `exact.hybrid` table, I encoded all occupied long slots in their existing hash order. The six arms cross two representations with three compressors. The first representation stores form and lemma literally. The second keeps the entire form and represents the lemma by a two-byte cut length and its literal replacement suffix. Both use four bytes of record fields before compression. For each compressed arm one 8-bit FSST codebook serves a single language's table. Each record can be decoded independently. The pilot uses the authors' FSST and OptFSST routines from one pinned source tree. [FSST, PVLDB 2020](https://www.vldb.org/pvldb/vol13/p2649-boncz.pdf) · [OptFSST, ADMS 2026](https://www.vldb.org/2026/Workshops/VLDB-Workshops-2026/ADMS/ADMS26_4.pdf) · [Pinned implementation](https://github.com/Hedi-Chehaidar/optfsst/tree/be06199760288005e2ebdc11fbd0f087903c0476)

| Long-slot representation | Codec | Accounted runtime data across 172 packages, bytes | Reduction vs. shipped bytes | Median reduction per language |
|---|---|---:|---:|---:|
| Full form and lemma | Raw (shipped) | 578,374,683 | 0% | 0% |
| Full form and lemma | FSST | 347,325,025 | 39.95% | 22.37% |
| Full form and lemma | OptFSST | 340,054,797 | 41.21% | 22.26% |
| Full form and lemma edit | Raw | 432,410,848 | 25.24% | 11.83% |
| Full form and lemma edit | FSST | 277,946,418 | 51.94% | 28.03% |
| Full form and lemma edit | OptFSST | 274,837,485 | **52.48%** | **28.06%** |

The combined OptFSST arm saved 64.47% of Russian runtime bytes, 52.01% of Finnish and 34.17% of English. It reduced size in 169 languages. After including the codebook, Tagalog grew by eight bytes and Umbrian by 24. The sign-language package contributed the same 30,685 bytes to every arm. FSST plus the same edit came within **0.54 percentage points** of OptFSST's pooled reduction. [Measurements](pilot.json)

The byte count replaces the original long-record blob with the sum of the measured encoded record lengths and exported codebook length. It retains the header, alignment, double array, pilots and a 32-bit offset per slot boundary, as well as every other file listed in the runtime manifest. A reader can locate the codebook immediately after the encoded blob using the blob-length header field. Byte accounting covers the data payload. Compressed-wheel size, filesystem allocation, modified manifests, reader code and runtime working memory are separate quantities. All 13,139,002 occupied records passed a byte-for-byte round trip, including restoration of each original form and lemma in the edit arm. Two executions produced identical per-language results. A complete reader, arbitrary-query tests and latency measurements remain part of the proposed comparison. [Size calculation](measure.py) · [Encoder and round-trip check](record_sizes.cpp)

## Literature and experimental arms

| Candidate and source | What to build and what to compare |
|---|---|
| **OptFSST and FSST.** Chehaidar et al. (ADMS 2026) improve symbol-table construction and use dynamic programming to encode strings. A shared codebook supports independent decoding. [OptFSST paper](https://arxiv.org/abs/2607.11271) · [Original FSST](https://doi.org/10.14778/3407790.3407851) | Time the six pilot arms with the same hash and short-key trie. A long miss may require decoding a slot to reject a close nonmember. Also test compression of the shared lemma pool at a fixed index to see how the smaller addressable footprint trades against decoding on each hit. The published experiments used string columns. Applying the method to form–lemma slots is this study's adaptation. |
| **CoCo-trie and C²-Marisa.** Boffa et al. (2024) select and encode entire subtries as searchable macro-nodes. Zhang, Zhao and Xu combine cache-conscious bitvector navigation with adaptive compression of single-child paths. The C² paper was available in 2026 and appears in the EDBT 2027 proceedings. [CoCo paper](https://doi.org/10.1016/j.is.2023.102316) · [C² paper](https://openproceedings.org/2027/conf/edbt/paper_35.pdf) · [C² code](https://github.com/gt-alg-kit/C2) | Compare exact key lookup with a common lemma-ID layer. Include plain C++ MARISA from the same implementation family alongside the lab's Rust port. Charge the terminal-ID-to-value array and any rank support. CoCo's topology IDs can differ from input order. Use a configuration covering the full UTF-8 byte alphabet, retain complete keys and check prefix-related misses. The C² study shuffled successful queries and omitted miss latency. Its FST comparator is the *Fast Succinct Trie*. udlex's `fst::Map` implements a finite-state transducer. [CoCo API](https://github.com/aboffa/CoCo-trie/tree/dcea4eecb7fa2eef2ff997c52466cc7063ffc379) |
| **Two-level massive string dictionaries.** Ferragina, Rotundo and Vinciguerra (2025) split sorted strings into compressed blocks. A succinct Patricia trie indexes the first string of each block. The authors evaluated up to 3.5 billion strings. [Paper](https://doi.org/10.1016/j.is.2024.102490) · [Code](https://github.com/MariagiovannaRotundo/Two-level-indexing) | Apply this to the largest external dictionaries. Search one block, confirm all bytes of the form and fetch its lemma by rank. Compare the authors' rear coding with a simple block front-coding control. Vary block size and test warm and memory-limited lookup. Charge the upper index, blocks, payloads and any workload-trained cache. Fit the cache on development queries. |
| **Inflectional templates.** Straková, Straka and Hajič (2014) infer shared templates when encoding an enumerated morphological dictionary. Hlaváčová et al. (LREC 2026) describe the manually maintained inflectional and derivational patterns behind MorfFlex CZ. The latter provides linguistic motivation. MorphoDiTa supplies a generic encoder for enumerated triples. [MorphoDiTa](https://aclanthology.org/P14-5003/) · [Encoder manual](https://ufal.mff.cuni.cz/morphodita/users-manual) · [MorfFlex](https://aclanthology.org/2026.lrec-1.899/) | Rebuild from the study's own deduplicated pairs, grouped by lemma with one dummy tag. Use dictionary-only exact-case lookup. The public generic analyzer also tries case variants and special-token analyses, so use the lexical lookup underneath those steps. Match the exact accepted form set, charge exceptions and compare against the existing interned `cut+suffix` rule table. Expect the trade-off to vary with forms per lemma and template reuse. [Generic analyzer source](https://github.com/ufal/morphodita/blob/master/src/morpho/generic_morpho.cpp) |

## Proposed comparison for the paper

Three published measurements help set expectations. OptFSST raised the compression factor of 8-bit FSST by 7.3% on average across 92 string datasets. C²-Marisa reduced average positive lookup time by a factor of 1.42 relative to the authors' MARISA comparator. MorphoDiTa's Czech experiment encoded a 6.7 GB textual list of form–lemma–tag triples in a 2 MB dictionary binary. Each result uses a different input, denominator and operation. The experiment below uses complete form-to-lemma lookup as the common operation. [OptFSST evaluation](https://arxiv.org/abs/2607.11271) · [C² evaluation](https://openproceedings.org/2027/conf/edbt/paper_35.pdf) · [MorphoDiTa, §3.1](https://aclanthology.org/P14-5003.pdf)

1. **Freeze the mapping and separate the two datasets.** For the released single-resource catalog, verify the wheel and generation digests and emit one sorted, length-prefixed UTF-8 `(form, lemma)` stream per language and table. Record its digest, distinct form and lemma counts, and original codec. For the multisource experiment, freeze its own inventory, source order and generations and keep separate rows for `exact`, `lower` and `external`. Existing Q5 builds `exact` from training rows and can read `external` from a shipped generation. Compare the pair-stream hashes before identifying a reconstructed table with a shipped table. Size census can cover every available language. For timing, keep the existing 14-language panel and declare which layers are present. [Q5 inputs](../encoding/src/main.rs) · [Timing panel](../encoding/run_final.sh)
2. **Compare against the strongest applicable udlex baseline.** Keep the shipped hybrid for corpus tables and the actual per-bundle `.da`, `.map` or `.inline` choice for external data. Include the existing MARISA, `fst+ids`, PtrHash with full-key verification, and `+rule` as controls. First change only the representation of long records. Next compare alternative indexes with identical payloads. Finally compare complete packages, allowing each method its native value representation. Count each shared lemma pool once. A short fingerprint or a perfect hash alone admits nonmembers and changes the task. [PtrHash, SEA 2025](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SEA.2025.21) · [Existing candidates](../encoding/src/cands.rs) · [Value-layer implementations](../encoding/src/dict.rs)
3. **Prove equivalence before timing.** Enumerate all member keys and compare every output byte to the frozen mapping. Check accepted-set equality wherever enumeration is available. Use natural misses and near misses produced by extending a valid key, truncating a key, or changing a late Unicode character. Run mixed scripts, combining marks, locale-specific case and identity hits through the public sentence API. Keep a checksum of complete lemma bytes and compare the responding cascade stage where the API exposes it. Add a full-materialization timing mode because the current microbenchmark sink consumes the length and boundary bytes of each lemma. [Current result interface](../encoding/src/dict.rs)
4. **Use the traffic each table actually sees.** Collect the original token order and the conditional probes reaching each stage from the production normalizer and cascade. The existing lab reconstructs external probes using Rust's generic lowercase operation. Traces from the reader preserve its language-sensitive case handling. Report hit-only, miss-only, uniform-key and corpus-frequency workloads plus full sentence throughput. Record the hit rate, UTF-8 length distribution, adjacent-key prefix lengths, form–lemma shared-prefix lengths, and distinct edits per language. These distinguish string-index effects from morphological reuse. Select block sizes, thresholds and optional per-language choices on development traffic. Freeze them before timing on the screened transfer corpora. [Existing workloads](../encoding/src/data.rs) · [Transfer protocol](../transfer-protocol.md)
5. **Measure bytes and service cost on matching units.** Publish bytes per distinct pair for each table, complete runtime data and distribution archive bytes, and the component breakdown including value arrays, verifiers and codebooks. Record build time and peak RSS, open-to-first-answer time, warm and cold RSS/page faults, p50/p95 query latency by hit/miss and end-to-end tokens/s. Report tail latencies from individual queries or explicitly sized batches. Measure cold start in fresh processes with documented page-cache state and equal integrity checks. Record heap materialization by an adapter. Keep each candidate in its own process, pin one core, use the same input order, and alternate baselines and candidates in balanced blocks over independent sessions.
6. **Report the size–speed frontier.** Show one point per method per language, joined to its own baseline. Give the median per-language size reduction, pooled bytes, and languages improved/tied/regressed. For speed, report paired ratios with 95% intervals from independent session/round blocks and distinguish between-run noise from variation across languages. A concrete deployment question is which exact representation uses the fewest bytes with a lower 95% bound of at least 0.95 for held-out end-to-end throughput relative to the shipped method. This is a proposed margin to fix before timing. Publish the unrestricted frontier, build failures and supported-language counts alongside it. Treat the present size census and the already-inspected anchor workloads as exploratory.

## Reproduction

From this directory in the paper worktree, with Python 3 and Clang supporting C++20, run the commands below. The work directory holds the compiler output and upstream sources. The pilot used Apple Clang 21 on arm64 and the scalar 8-bit implementation. The pinned source requires Clang's narrowing-diagnostic override.

```sh
work=$(mktemp -d)
git clone -q https://github.com/Hedi-Chehaidar/optfsst.git "$work/optfsst"
git -C "$work/optfsst" checkout -q be06199760288005e2ebdc11fbd0f087903c0476
clang++ -std=c++20 -O3 -DNDEBUG -DFSST_DISABLE_AVX512=1 \
  -Wno-c++11-narrowing -Wno-parentheses-equality -I"$work/optfsst" \
  record_sizes.cpp "$work/optfsst/libfsst.cpp" "$work/optfsst/fsst_avx512.cpp" \
  -o "$work/record_sizes"
python3 measure.py ../../../../dictionaries/ud-2.19 "$work/record_sizes" > "$work/pilot.json"
cmp pilot.json "$work/pilot.json"
```

For language or aggregate row `r`, the accounted bytes of arm `a` equal `r.runtime - r.raw + r[a]`. Missing record-blob fields contribute zero. The input catalog SHA-256 is `7042aaa89bd7b006fbbc5362eeb6eb1bef732ca34da960560eb939c7d22df97f`. [Full receipt](pilot.json) · [BibTeX](references.bib)
