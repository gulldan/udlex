# Evaluation protocol for the 1.0.0 project snapshot

Fixed on 18 November 2026 before scoring the current packages. The engine base is the canonical main commit `7afe2fe8f3ea6ea56fff835bbc61d8af49da731f`. The tagged package source is `2270bc1cb1c7144a85cf581318ca669417608fe4`. Their Python and Rust sources and build inputs agree. The GitHub assets were in draft when sampled. The asset inventory pins every byte used below. Historical multi-dictionary research builds have different inputs.

## First measurement

Use the packaged dictionary for every one of the 172 ISO codes. Each manifest record names one resource. Include every official UD 2.18 test treebank whose file prefix maps to one of the 172 languages in the frozen code map. Count syntactic words (integer IDs) with available surface and lemma strings. Omit withheld forms and unknown lemmas marked with an underscore. Use the ordinary sentence API, case-sensitive equality and the packaged defaults, with user dictionaries disabled. Compare the full engine against copying and against the same dictionary with suffix rules disabled. Neither alternative uses gold at inference.

Audit the declared input files for every UD-derived dictionary, including all splits if a source used several. Read the exact source bytes named in the package and compare their digests. Exclude a test file named as a dictionary input, including when the same upstream file was used at a different revision. Within the same treebank exclude source document and sentence identifiers. Across all treebanks of the same language exclude matching source sentences and repeated evaluation sentences. Sentence matching uses case folding, NFC and whitespace removal on joined syntactic words. Traverse treebanks and test files in name order. Keep a treebank ledger with reasons for exclusion and a row for every packaged language. Report both counts when visible forms or gold are absent. These checks cover declared inputs. Overlap in the upstream material used to compile an independently obtained dictionary can remain unknown. Masked corpora and translated material also limit provenance checks.

Report unweighted mean language accuracy and pooled token accuracy over the retained examples. Pool treebanks within each language before the macro average. Also report improvements and regressions against copying and the suffix ablation, plus an external-resource-only sensitivity estimate. Preserve block counts by document where available and by sentence otherwise. The paired 95% percentile interval for the difference holds languages fixed and resamples blocks within each treebank, 2,000 times with seed 20261118. The interval describes sampling variation for this cohort.

## Source-priority experiment and transfer

Changing priority in a one-source package cannot identify a priority effect. A separate experiment on the same engine needs an inventory with at least two sources for each contributing language. Build declared, best-single, greedy, exact-train and dev-confirmed arms on common source bytes, train/dev splits and a fixed cascade. Select policies without looking at target lemmas. Retain languages where the gate makes no change. Before running those arms, pin the research dictionaries, their licenses and all source/target splits in a separate manifest.

Transfer remains a research question. Can the policy learned on one corpus improve accuracy on independently collected documents of the same language? Screen the provenance and document overlap of new UD 2.19 treebanks against all material used to fit or inspect a policy. Score the two frozen policies on identical target tokens only after eligibility is fixed.
