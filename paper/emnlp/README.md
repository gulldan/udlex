## Что измерено на сервере

Проверены движок и все 172 словаря. Все 739 примеров из манифестов воспроизвелись. В каждом словаре указан один исходный ресурс. У 101 словаря это корпус UD. Для 57 использован его тестовый файл, для 43 — обучающий, ещё для одного — все три разбиения. Остальные 71 пакет собраны из других лексических ресурсов. [Опись словарей, источников и лицензий](evidence/snapshot.json)

В официальном UD 2.18 нашлось 330 подходящих по языковому коду тестовых файлов. Исключены 58 файлов, уже использованных при подготовке словарей, и повторяющиеся предложения. Остались 261 корпус, 121 язык и 4 214 133 слова с доступной формой и эталонной леммой. Для 47 языков все доступные тесты вошли в словарь, для трёх после фильтрации нет оцениваемых слов, для туркменского нет тестового файла в официальном архиве этой версии. Все 172 языка сохранены в приложении. [Реестр языков](evidence/languages.json) · [Реестр корпусов](evidence/treebanks.json) · [Дистрибутив UD 2.18](https://hdl.handle.net/11234/1-6149)

Среди 69 оценённых языков с внешним лексическим ресурсом средняя точность штатной конфигурации равна 56,32%, при отключённых правилах — 63,62%. ## Какой вывод относится к выбору словарей

В прежней исследовательской сборке для одного языка могли конкурировать несколько словарей. Сохранённый отчёт содержит 98 языков с обучающими данными. У 15 отдельная проверка на dev поддержала изменение приоритета или состава источников. В турецком случае получились 69 исправлений и 38 регрессий на 872 позициях после корпусного поиска. Это свидетельство относится к конфигурации и разбиению этого опыта. Обычный пакет 1.0.0 содержит один ресурс, поэтому сравнение пакета с копированием или с отключёнными правилами оценивает другой эффект. Журналы чисел предыдущей конфигурации хранятся в исследовательском архиве. [Выдержка из train/dev-отчётов с хешами исходников](evidence/policy-development.json)

## Что осталось до подачи

| Работа | Что нужно получить | Ориентир для одного исследователя |
| --- | --- | ---: |
| Несколько словарей на движке 1.0.0 | Зафиксировать словари и разбиения. Сравнить объявленный порядок, один лучший словарь, жадный порядок, точный train-оптимум и политику после dev на одних токенах. Посчитать исправления и регрессии в полном каскаде | 3–5 рабочих дней |
| Независимый корпус | Проверить происхождение документов и пересечения с train/dev/test. Зафиксировать допуск до просмотра результатов. Сравнить политики с одинаковыми словарями на целевом корпусе | 4–7 дней при наличии разметки |
| Разбор ошибок и финальная редактура | Вручную классифицировать парную выборку ошибок, сверить утверждения и цитаты, подготовить анонимные материалы и заполнить форму ARR | 2–4 дня |

Итого ориентировочно 9–16 человеко-дней после этого прогона. Перенос порядка на новый корпус остаётся исследовательским вопросом. Доступность независимых документов для языков с конфликтующими словарями определяет основной риск для этого срока. Шаблон использует анонимный режим ACL для длинной статьи. Основной текст заканчивается на седьмой странице. [Требования ARR](https://aclrollingreview.org/cfp) · [Редакция шаблона ACL](https://github.com/acl-org/acl-style-files/tree/d5adc823ff0f80f98c80405ca0ab66c68e684409)

## Воспроизведение

Команды запускаются из корня исследовательской ветки. Переменная `run_dir` указывает на отдельный каталог данных. Утилита `gh` использует доступ к черновику, если файлы не доступны локально. Параметр `--cache` у команды получения пакетов можно указывать несколько раз. Совпадение каждого файла проверяется по SHA-256. Для исходного запуска использовались Linux x86-64 и CPython 3.12.13.

~~~sh
run_dir=$(mktemp -d)
study=paper/emnlp/experiments
python3 "$study/fetch_assets.py" "$run_dir/assets"
python3 -m venv "$run_dir/venv"
py="$run_dir/venv/bin/python"
"$py" -m pip install --no-index "$run_dir/assets/udlex-1.0.0-cp311-abi3-manylinux_2_34_x86_64.whl"
"$py" "$study/verify_snapshot.py" . "$run_dir/assets" "$run_dir/compiled" "$run_dir/snapshot.json"
"$py" "$study/verify_sources.py" . "$run_dir/assets" "$run_dir/source-identity.json"
mkdir -p "$run_dir/ud"
curl -fL https://lindat.mff.cuni.cz/repository/server/api/core/bitstreams/d91b1ffc-fc31-41a0-bd8f-3b876864a1d5/content -o "$run_dir/ud218.tgz"
tar -xzf "$run_dir/ud218.tgz" -C "$run_dir/ud"
"$py" "$study/evaluate.py" "$run_dir/assets" "$run_dir/compiled" "$run_dir/snapshot.json" "$run_dir/ud218.tgz" "$run_dir/ud/ud-treebanks-v2.18" "$run_dir/paired" --jobs 6
"$py" -m pip install numpy==2.5.1
"$py" "$study/summarize.py" "$run_dir/paired" "$run_dir/snapshot.json" "$run_dir/result"
~~~

Для проверки агрегации без загрузки данных достаточно Python и NumPy 2.5.1. Используются обезличенные счётчики по блокам. Документы служат блоками там, где доступны границы, предложения — в остальных случаях.

~~~sh
python3 paper/emnlp/experiments/summarize.py paper/emnlp/evidence/paired-counts.json.gz paper/emnlp/evidence/snapshot.json "$run_dir/replay"
cmp paper/emnlp/evidence/summary.json "$run_dir/replay/summary.json"
~~~

Главный документ Overleaf — `udlex-emnlp.tex`. Таблицы можно сформировать из проверенных результатов и собрать PDF локально.

~~~sh
python3 paper/emnlp/experiments/render_tables.py
mkdir -p output/pdf
tectonic --outdir output/pdf paper/emnlp/udlex-emnlp.tex
~~~
