# udlex

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md)

udlex — словарный лемматизатор. Он ищет каждый токен в скомпилированных
таблицах, выученных из трибанков Universal Dependencies и открытых словарей, а
незнакомые слова угадывает по суффиксным правилам. Ядро написано на Rust; пакет
добавляет привязки для Python и командную строку, а из того же ядра собирается
C-библиотека. Нейросети нет: ничего не нужно запускать на GPU, и ответы
детерминированы.

## Установка

С [uv](https://docs.astral.sh/uv/) добавьте в проект движок и словарь:

```sh
uv add udlex
uv add "udlex-dict-eng-nc @ https://github.com/gulldan/udlex/releases/download/v1.0.0/udlex_dict_eng_nc-1.0.0-py3-none-any.whl"
uv run udlex lemma eng mice were running
```

Нужен Python 3.11 или новее. Колёса собраны для Linux (x86_64, aarch64), macOS
(arm64, x86_64) и Windows (x86_64); на других платформах uv собирает пакет из
исходников, для этого нужен Rust.

Движок лежит на PyPI, словари — нет. Каждый язык — отдельное колесо в
[релизе v1.0.0](https://github.com/gulldan/udlex/releases/tag/v1.0.0), и `uv add`
по адресу колеса записывает его в `uv.lock`, как любую зависимость.
`uv run udlex install --dry-run fin rus` печатает адреса для любых языков.
`udlex install <iso> ...` ставит колёса в текущее окружение через `uv pip`
(или pip, если uv нет); внутри uv-проекта он печатает команду `uv add`, потому
что `uv sync` удаляет пакеты, которых нет в lock-файле.

Колёса называются `udlex_dict_<iso>-1.0.0-py3-none-any.whl`, у
[некоммерческих](#лицензии) пакетов, таких как английский, после кода стоит
`_nc`. Они ставятся в пространство имён `udlex_bundle`, где их находят
`udlex.load` и командная строка. Каждый пакет есть и в виде архива
`udlex-dict-<iso>-1.0.0-bundle.tar.gz` (с `-nc` так же), который распаковывается
в `bundle/<iso>`. Несколько архивов можно распаковать в одно место; udlex читает
`./bundle`, если колёс словарей нет, либо каталог из `UDLEX_BUNDLE`, либо
переданный в `udlex.load(directory, iso)`.

## Использование

```py
import udlex

lexicon = udlex.load("eng")  # загружайте один раз на процесс; безопасно для потоков
print(lexicon.lemmatize(["The", "mice", "were", "running"]))
```

На вход подаётся список токенов: токенизатора в udlex нет. Языки задаются кодом
ISO 639-3. Из командной строки:

```sh
uv run udlex lemma eng mice were running
uv run udlex languages
```

### Попробовать без скачивания

Пример собирает словарь из двух слов по таблице `форма<TAB>лемма` и запускает
его. Сохраните как `quickstart.py` и выполните `uv run quickstart.py`.

```python
from pathlib import Path

import udlex

bundle = Path("example-bundle")
bundle.mkdir()
words = bundle / "lemmas.tsv"
words.write_text("cats\tcat\nmice\tmouse\n", encoding="utf-8")

udlex.build_lexicon(
    str(bundle / "eng"),
    train=None,
    dev=None,
    test=None,
    paradigms=[("example", str(words), False, False)],
    name="eng",
    language="English",
    iso639_3="eng",
)
lexicon = udlex.load(bundle, "eng")
print(lexicon.lemmatize(["cats", "mice", "unknown"]))
# ['cat', 'mouse', 'unknown']
```

```sh
uv run udlex --bundle example-bundle lemma -q eng cats mice
```

## Точность

Точное совпадение леммы на золотых токенах Universal Dependencies 2.19
([`evaluation.json`](dictionaries/catalog/evaluation.json)). *Копия* возвращает
каждый токен без изменений.

| Языков | Оценка | udlex, макро % | Копия, % |
| --- | --- | ---: | ---: |
| 103 | официальный тест | 89,85 | 58,41 |
| 109 | двукратная оценка (нет обучающей части) | 73,87 | 57,54 |
| 12 | нет золотых лемм: не измерено | — | — |

Сравнение с другими лемматизаторами на одних и тех же тестовых словах (из
[`benchmarks/generated/numbers.tex`](benchmarks/generated/numbers.tex)).
Каждая строка усредняет по языкам, которые есть у обеих систем, без языков, чьи
тестовые предложения видела модель конкурента, поэтому строки между собой не
сравнимы.

| Система | Языков | Система, % | udlex, % |
| --- | ---: | ---: | ---: |
| Stanza | 65 | 95,32 | 93,81 |
| UDPipe 2 | 77 | 94,48 | 93,47 |
| Trankit | 46 | 91,32 | 94,44 |
| UDPipe 1 | 44 | 91,36 | 95,16 |
| simplemma | 33 | 90,75 | 95,44 |
| spaCy sm | 17 | 89,55 | 95,77 |
| spaCy lg | 17 | 90,63 | 95,77 |

Stanza и UDPipe 2 точнее udlex примерно на 1–1,5 п.: это нейросетевые модели,
которые видят всё предложение и части речи. Остальные системы в среднем
уступают udlex.

## Скорость и память

Все системы мерились на одной машине — AMD Ryzen 9 7950X (16 ядер) и RTX 4090 —
на токенизированных тестовых предложениях UD 2.19 всех языков, которые
поддерживает система. Скорости — медианы по языкам. «udlex быстрее» — среднее
геометрическое по языкам системы того, во сколько раз ядро udlex на Rust быстрее
на одном ядре. «Параллельно» — лучшее из 16 процессов и 16 потоков, у нейросетей —
одна GPU. «Пиковая память» — резидентная память процесса замера на одном ядре,
вместе с тестовым текстом: медиана системы, затем udlex на тех же языках.

| Система | Языков | Слов/с, одно ядро | udlex быстрее, × | Слов/с, параллельно | Пиковая память, МБ |
| --- | ---: | ---: | ---: | ---: | ---: |
| **udlex, Rust** | 169 | 54.4M | — | 759M | 147 |
| **udlex, Python** | 169 | 18.0M | — | 142M | 1,172 |
| simplemma | 37 | 6.6M | 5.4 | 57.8M | 324 / 110 |
| LemmaGen3 | 17 | 3.5M | 9.5 | 32.5M | 1,445 / 118 |
| CoreNLP | 1 | 27k | 1,965 | 336k | 1,600 / 111 |
| spaCy sm | 20 | 27k | 1,422 | 218k | 773 / 114 |
| spaCy lg | 20 | 25k | 1,568 | 165k | 1,546 / 114 |
| UDPipe 1 | 50 | 15k | 2,177 | 151k | 153 / 99 |
| Stanza | 90 | 4.5k | 8,160 | 16k (GPU) | 1,240 / 99 |
| spaCy trf | 8 | 278 | 143,271 | 20k (GPU) | 2,840 / 111 |
| Trankit | 53 | 74 | 433,457 | 3.9k (GPU) | 4,665 / 94 |

На одном ядре udlex обрабатывает от 6,2 млн до 858 млн слов в секунду в
зависимости от языка. simplemma, самый быстрый из остальных, быстрее только на
грузинском, на 1 %. Python-привязка ускоряется в 1,46 раза на 16 потоках и в 8,9
раза на 16 процессах; её память включает Python-списки токенов тестового текста.
UDPipe 2 по скорости не мерился. Цифры зависят от процессора и от состава
токенов. Значения взяты из
[`numbers.tex`](benchmarks/generated/numbers.tex), квитанции — в
[`benchmarks/evidence/speed`](benchmarks/evidence/speed).

## Ограничения

- **На входе токены, на выходе леммы.** Токенизатора, разбиения на предложения
  и теггера нет. Сначала разбейте текст.
- **Без контекста.** Каждый токен получает одну лемму независимо от
  предложения. Форма с несколькими возможными леммами (англ. *saw*: *see* или
  *saw*) всегда получает одну и ту же. Это главный разрыв со Stanza и UDPipe 2.
  Аргументы `upos=` и `context=` у `lemmatize` действуют только на словари,
  собранные с контекстными ключами, а пакеты 1.0.0 собраны без них.
- **Незнакомые слова** угадываются по суффиксным правилам из трибанка. На словах,
  которых словарь не видел, это слабее нейросети. `use_rules=False`
  (`--lookup-only` в командной строке) возвращает такой токен без изменений.
- **Точность зависит от языка**: от почти 100 % до менее 50 %; сверьтесь с
  [таблицей языков](docs/languages.md). Для 109 языков без обучающей части
  точность — двукратная оценка на маленьких трибанках, у 12 языков золотых лемм
  нет совсем.
- **Частично поисковые числа.** Для языков без официального dev замену dev
  ввели после первой оценки на тесте.
- **Нет лемм от языковой модели.** В выпускных словарях нет лемм, размеченных
  языковой моделью; каждый пакет перечисляет свои источники в `SOURCES.json`.
- **Некоммерческие трибанки.** 39 пакетов, в том числе английский, чешский,
  арабский и итальянский, выучены из трибанка с некоммерческой лицензией и
  годятся только для некоммерческого использования.

## Лицензии

Код распространяется по лицензии [MIT](LICENSE).

У каждого пакета словаря своя лицензия, она следует из его источников: в
v1.0.0 184 пакета под CC BY-SA (182 версии 4.0, 2 версии 3.0), 39 под
CC BY-NC-SA 4.0 и 1 под CC BY 4.0. Пакеты с суффиксом `-nc` — только для
некоммерческого использования. Внутри пакета каждая таблица сохраняет лицензию
своего источника, а `SOURCES.json` перечисляет источники с URL, версией,
автором и лицензией, как `meta.json` у spaCy. Если поставляете словарь, сохраните
его `NOTICE` и `SOURCES.json` и соблюдайте его лицензию. Все источники и
лицензии пакетов — в [DICTIONARY_LICENSES.md](DICTIONARY_LICENSES.md).
